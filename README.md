# 💰 Smart Financial Advisor (Streamlit)

> Interactive financial analysis and long-term savings simulator  
> Built with Python & Streamlit

---

## 📊 What is this?
**Smart Financial Advisor** is a Streamlit-based application designed to analyze personal financial data, generate a financial score, and simulate long-term savings scenarios.

This repository contains a **DEMO version** of the project.

---

## 🎯 Who is this for?
- Python developers
- Freelancers & consultants
- Fintech startups (MVP)
- Students & bootcamps
- Anyone learning financial analysis with Python

---

## 🚀 Key Features
- Financial dashboard (income, expenses, savings)
- Financial health score (0–100)
- Automatic insights & recommendations
- Long-term savings simulator
- Scenario comparison (pessimistic / realistic / optimistic)
- Multi-language support (ES / EN)
- Built with Streamlit
